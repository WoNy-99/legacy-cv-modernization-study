# Legacy CV Pipeline Modernization Study

**Engineering Case Study · Experiment Log · Design Study**

오래된 Computer Vision 파이프라인의 현대화 가능성을 검토하며 겪은 문제와 설계 판단을 정리한 개인 학습 기록입니다. 전체 마이그레이션은 완료하지 못했습니다. 호환성, 입력 검증, 실행 환경, 작업 상태 관리와 실패 분석을 중심으로 구성했습니다.

> 이 저장소는 회고를 바탕으로 새로 작성한 **문서형 포트폴리오**입니다. 과거 구현 코드는 보존되어 있지 않으며, 실행 가능한 제품이나 재현 가능한 벤치마크를 제공하지 않습니다. 과거 대화에 남아 있는 본인의 설명·실행 출력·작업 보고를 구분해 요약했습니다.

## 한눈에 보기

| 구분 | 내용 | 현재 상태 |
|---|---|---|
| 과거 | 입력 검증, 라벨 검토, 환경 관찰, 작업 복구 시도 | 일부 실행 기록만 남음 |
| 현재 | 동작 보존을 우선하는 현대화 설계 정리 | 문서 작성 완료, 구현 검증 없음 |
| 최종 목표 | 호환성을 확인한 뒤 최적화를 비교하는 파이프라인 | 미완료 |
| 공개 산출물 | 실험 회고, 실패 분석, 설계안, 검증 계획 | 이 저장소의 문서 |

## 문제의식

기존 실행 환경을 새로운 환경으로 옮길 때, 단순한 버전 교체와 실제 동작의 보존은 별개의 문제였습니다. 성능을 개선하고 싶었지만 입력 조건, 평가 준비, 작업 상태 관리에서 먼저 막히는 일이 있었습니다. 실행이 일부 진행된 것과 전체 검증이 끝난 것을 구분하는 기준도 필요했습니다.

이 기록은 성공한 시스템을 소개하기보다, **무엇을 시도했고 어디까지 확인했으며 무엇을 아직 증명하지 못했는지** 설명합니다.

## 내가 수행한 범위

- 기존 환경을 사용하며 발생한 문제를 보고하고, 실행 출력과 AI 보조 작업 보고를 바탕으로 다음 작업을 판단했습니다.
- 외부 가상환경에서 자동 라벨링을 시도했으며, 평가 조건에 맞는 구간이 없다는 결과를 확인했다고 기록했습니다.
- 백업 및 Git 정리 과정에서 발생한 오류를 확인하고, 작업 범위와 이미 반영된 변경을 구분하려고 했습니다.
- 기존 동작을 유지하면서 실행 환경을 바꾸는 방향과, 작업별 변경 제한·검증 조건을 논의했습니다.

AI 도구를 분석·작업 지시·리뷰에 활용했습니다. 남아 있는 자료만으로 코드별 직접 작성 비중을 입증할 수 없으므로, 전체 구현을 독자 개발했다는 주장은 하지 않습니다.

## 다루는 기술 주제

Python 실행 환경, TensorFlow → PyTorch 전환 검토, CUDA/GPU 실행 환경, OpenCV 전처리, FFmpeg·ffprobe 입력 검사, Git 작업 상태 관리, 라벨 검토 절차, 수치 동등성 검증 설계.

이 목록은 **문서에서 다루는 주제**이며, 모든 기술을 사용해 구현을 완료했다는 의미가 아닙니다.

## 결과와 한계

- 전체 현대화, 학습·추론의 동등성, 장시간 안정성은 입증하지 못했습니다.
- 성능 향상률이나 정확도 개선 수치를 성과로 제시하지 않습니다.
- 원래 응용의 상세 내용과 데이터는 문서 범위 밖에 있습니다. 그림·실행 자료를 새로 만들어 과거 결과처럼 제시하지 않았습니다.
- 특정 산업의 제품 개발, 양산 적용 또는 기업 과제를 수행한 사례가 아닙니다.

회고 정리일: 2026-09-21. 과거 기록과 현재 작성한 설계는 각 문서에서 별도로 표시합니다.
